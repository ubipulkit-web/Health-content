# Health Content Portfolio - Dr Pulkit Mandal

A static, accessible portfolio site of three consumer health writing samples.

## Structure
- `content/*.md` - the article text (edit these)
- `build.py` - Python script that turns the Markdown into HTML (`pip install markdown`, then `python build.py`)
- `index.html`, `articles/*.html` - generated pages
- `assets/style.css` - styling (light and dark mode, print-friendly)

## Publish on GitHub Pages
1. Create a new GitHub repository (for example `health-content-portfolio`) and push these files to the `main` branch.
2. In the repository go to Settings > Pages, choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
3. Your site will appear at `https://<your-username>.github.io/<repository-name>/` within a minute or two.
